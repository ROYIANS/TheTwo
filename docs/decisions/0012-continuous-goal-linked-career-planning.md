# ADR-0012：非求职阶段持续积累并围绕职业目标提供规划

## Context

作为个人职业决策系统，择途需要决定用户没有正在求职时是否仍然参与。系统可以只在求职、转型或离职等重大选择出现时使用，也可以持续积累职业事实并围绕目标提供准备，还可以扩张为管理待办、学习、工时、绩效和知识的完整职业操作系统。

只在决策时使用会使职业画像在关键时刻过时；管理全部日常职业生活则会与通用效率、学习和知识管理工具重叠，使产品失去边界。

## Decision

1. 用户没有正在求职时，择途主要辅助职业规划。
2. 系统持续积累项目成果、能力证据、职业目标、偏好和现实限制的变化，让职业画像在下一次重大选择前保持可用。
3. 系统围绕用户明确的职业目标帮助发现能力与证据差距、比较可行路径并准备下一步。
4. 非求职阶段的能力必须与职业画像或明确职业目标直接相关。
5. 择途不接管日常待办、工时、通用知识管理、完整课程学习或全部个人品牌运营。
6. 系统可以建议值得学习或建设的内容，但不因此成为通用在线教育或项目管理平台。

## Consequences

正面影响：

* 职业画像能够在两次求职之间持续演化；
* 用户可以提前积累下一次职业选择所需要的真实证据；
* 职业规划与求职结果使用同一套长期上下文；
* 通过“是否与明确职业目标直接相关”判断相邻需求是否属于范围。

代价与风险：

* “与职业目标相关”仍可能被过度解释，需要持续防止范围膨胀；
* 用户需要愿意在非求职期记录或导入职业变化；
* 规划建议可能依赖不完整或变化中的目标；
* 与学习工具、知识库和项目管理工具之间需要保持清楚集成边界。

## Alternatives Considered

### 只在重大职业选择出现时参与

范围最清晰，但缺少平时积累，关键决策到来时职业画像可能已经过时，未采用。

### 管理完整日常职业生活

能够获得大量连续数据，但会扩张为通用职业操作系统并与现有工具重叠，未采用。

## Supersession

无。
