# Work Records

`work/` 保存尚在推进或已经结束的阶段性工作。这里记录过程，但不是当前产品或系统规范的权威来源。

## 类型

* `discussions/`：AI 讨论、评审、需求探索和压力测试纪要；
* `proposals/`：等待决策的完整方案，出现第一份提案时再创建；
* `milestones/`：MVP 评估、范围基线、阶段报告和复盘，出现第一份材料时再创建。

## AI 讨论

默认保存结构化纪要，不直接倾倒聊天记录。纪要应包含：

1. 讨论背景与目标；
2. 已知事实和约束；
3. 主要候选方案与权衡；
4. 已确认结论；
5. 尚未解决的问题；
6. 晋升出的产品文档、决策记录或 spec。

完整原文只有在具备长期证据价值、适合公开且已移除敏感信息时，才保存到 `evidence/ai-transcripts/`。

## 关闭与晋升

讨论结束时：

* 将状态从 `open` 更新为 `closed`；
* 把当前产品结论更新到 `product/`；
* 把重要选择写入 `decisions/`；
* 把需要驱动实现的契约写入 `specs/`；
* 在 `related` 和正文中建立双向链接。

新建讨论时使用 [`../templates/discussion.md`](../templates/discussion.md)。
