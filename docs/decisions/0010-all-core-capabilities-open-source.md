# ADR-0010：全部核心产品能力持续开源免费

## Context

择途已经选择开源、自部署且不经营官方 SaaS 的产品模式，但仍需决定开源范围。常见选择包括：全部核心能力持续开源，通过赞助和支持性服务维持；采用 open-core，把高级连接器、分析或行业能力闭源收费；或者只承诺第一阶段开源，以后再决定。

职业画像、职位判断和决策闭环直接关系用户能否掌控自己的职业数据和系统建议。如果完整能力必须依赖闭源版本，用户仍会在关键职业决策上受制于项目维护方。

## Decision

1. 择途的全部核心产品能力持续开源免费。
2. 项目不采用通过闭源高级功能削弱社区版本完整性的 open-core 模式。
3. 职业画像、决策分析、求职闭环和扩展机制等核心能力不能被人为拆分为必须付费才能使用的闭源版本。
4. 项目可以探索赞助、捐赠、付费支持、部署协助、咨询或其他不限制核心能力的收入方式。
5. 收费不能成为用户获得完整核心产品能力、导出自己的数据或控制职业画像的前提。
6. 具体开源许可证需要结合社区贡献、商业使用和再分发目标另行研究和决定。

## Consequences

正面影响：

* 用户可以检查并长期掌控影响职业决策的完整系统；
* 社区版本不会退化为缺少关键能力的引流产品；
* 贡献者能够在同一完整产品上协作；
* 产品价值观与商业激励之间的冲突减少。

代价与风险：

* 放弃通过专有高级功能获得许可收入的直接路径；
* 赞助和支持性服务的收入可能不足以覆盖长期维护成本；
* 商业组织可以免费使用或二次部署项目，许可证策略需要认真设计；
* 需要防止未来以“非核心”为名把实际必需能力移入闭源版本。

## Alternatives Considered

### Open Core

基础能力开源、高级能力闭源，商业化更直接，但会让项目维护方有动机削弱免费版本，与完整核心能力由用户掌控的目标冲突，未采用。

### 仅承诺第一阶段开源

保留未来商业灵活性，但早期用户和贡献者无法判断项目长期边界，也可能在形成依赖后面对闭源转向，未采用。

## Supersession

无。
