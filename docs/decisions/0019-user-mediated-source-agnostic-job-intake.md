# ADR-0019：第一版采用用户主动且来源无关的职位输入

## Context

真实工作机会分散在 BOSS 直聘、智联招聘、V2EX、掘金、公众号、公司官网、朋友内推、邮件和线下沟通中。第一版可以尝试建设平台级自动聚合，也可以只支持单一招聘平台，或者把用户主动获得的任何机会作为输入。

官方资料初步核验显示，不同平台的接口和内容使用边界差异很大：V2EX 提供官方 API，BOSS 的 robots 对职位与推荐页面有广泛限制，掘金协议禁止未经许可使用机器人或蜘蛛监视和复制内容。把第一版建立在自动抓取上会带来平台依赖、合规和维护风险。

## Decision

1. 第一版主要依靠用户主动采集职位，输入保持来源无关。
2. 招聘平台、技术社区、公众号、公司官网、朋友内推、邮件或线下信息都可以作为来源。
3. 分析一条机会的最低核心信息是职位描述或主要职责要求，以及公司名称。
4. 系统尽量保留职位名称、来源渠道或 URL、采集时间、地点、薪资和原始截图或文本等信息。
5. 截图、文本、链接和浏览器当前页面是输入方式；进入系统后统一标准化并联网补充公司与职位信息。
6. 公开渠道连接器是后续增强，不是第一版成立条件。每个连接器实现前重新核验服务条款、官方接口、授权范围、限流和内容权利。
7. 不把绕过访问控制、反爬措施、账号限制或服务条款的大规模招聘平台爬取作为产品基础。

## Consequences

正面影响：

* 第一版不依赖任何单一招聘平台或数据合作；
* 朋友内推、公众号和公司官网等非标准机会也能进入同一判断流程；
* 用户可以立即使用，不必等待连接器完成；
* 平台合规风险与连接器维护成本被隔离到后续逐个决策。

代价与风险：

* 用户需要主动收集和提交机会，系统不会自动拥有完整职位池；
* 不同来源的信息完整度差异较大，需要处理缺失字段和截图识别错误；
* 来源不明或二手转述的信息可信度较低，系统必须展示未知项；
* 后续主动推荐能力需要在合规连接器或用户订阅来源基础上逐步建立。

## Alternatives Considered

### 第一版自动聚合主要招聘平台

职位数量更丰富，但平台授权、反爬、账号风控和持续维护风险过高，未采用。

### 第一版只支持 BOSS 直聘

符合发起者当前使用习惯，但会把产品绑定到单一平台，并排除朋友内推、公司官网和社区机会，未采用。

### 第一版以内置公开渠道推荐为主

可以减少用户采集工作，但不同渠道的正式接入依据尚未成熟，也不是验证职业决策价值的必要条件，未采用为主入口。

## Supersession

关于第一版职位内容输入方式的第 5 条已被 [ADR-0023](0023-manual-text-and-screenshot-job-intake.md) 部分取代：第一版正文输入收窄为文本和截图，URL 只记录为来源，浏览器当前页面采集后置。其余决定继续有效。
