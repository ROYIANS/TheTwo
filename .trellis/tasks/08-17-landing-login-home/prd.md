# 融合落地页与登录页首页

## Goal

把当前 prototype 的首页改造成落地页与登录入口融合的一体化首页：既能在首屏清楚表达产品定位，也能让唯一使用者直接进入登录流程。产品定位同步写入权威产品文档，避免界面叙事与系统边界继续漂移。

## What I already know

* 产品面向个人自用，不是团队协作或公共 SaaS。
* 产品支持独立部署，并保存使用者的个人信息。
* 一个部署实例只允许一个用户使用，不提供多用户注册、邀请、切换或协作能力。
* 本任务聚焦落地页改造，并参考 `D:/Code/Study/vidorra-life` 的落地页与 Trellis UI 规范。
* 目标体验是落地页与登录页融合，而不是把营销页和认证页拆成两个相互割裂的页面。

## Confirmed Decisions

* 采用完整融合首页：首屏左侧说明产品，右侧放真实工作流预览与唯一用户入口；下方只保留工作方式、数据边界和产品承诺等必要内容。
* 保留 prototype 的本地 reducer 演示登录，不伪造密码、注册或认证后端；入口明确标为演示体验。
* 参考 `vidorra-life` 的工程纸结构、线性秩序、衬线叙事和物理按钮，但不复制其品牌、文案或组件体系。
* 单实例单用户是产品正式边界，不只是首页文案；新增 ADR 取代 ADR-0022，并同步产品摘要。

## Requirements (evolving)

* 首页同时承担产品说明与登录入口职责。
* 首屏明确传达“独立部署、个人专属、信息由使用者自己掌控”的产品方向。
* 页面不得暗示支持多人注册、团队空间、组织、邀请或公共账号体系。
* 更新 `docs/product/` 下的权威产品文档，记录单实例单用户的产品边界。
* 视觉和交互参考 `vidorra-life`，同时保持本产品现有识别度。
* 桌面端和移动端均可完整阅读并完成主要操作。
* 首页至少包含品牌导航、融合首屏、三段核心工作方式、单用户数据边界、用户最终决定权和收尾入口。
* 入口文案必须诚实说明 prototype 当前是本地演示，不得暗示已实现真实账号注册或远端认证。
* 参考 `D:/Code/Study/vidorra-life/zed.html` 的结构性图案装饰，考虑节点、标尺、条码、网格、斜线舱壁等视觉原子，并将其转译为择途的职业研究档案语义。
* 图案必须服务分区、阅读方向或产品对象关系，不添加无业务含义的坐标、编号、代号或满屏纹理。
* Header 必须继承冷苔绿、冷白纸面与墨色主色体系，不再使用偏粉或暖红表面。
* 首页以留白和有限叙事为优先，不连续堆叠同等权重的营销区块；同一产品事实只表达一次。
* 不使用菱形节点或其他可被直接识别为 `vidorra-life` 的标志性装饰；参考项目只提供结构方法，不提供品牌符号。
* Zed 影响收敛为少量线性结构和局部研究网格，每个视觉区域最多保留一种主导纹样。
* 信息架构收敛为 Header、融合 Hero、三步工作方式、所有权与顾问边界、简短收尾；不再单独堆叠 statement、舱壁、所有权、AI 承诺和重复 CTA 区块。
* Hero 规格栏的横线不得贴住“独立部署 / 唯一所有者 / 职业研究与决策”文字底部；上下边界与三列内容之间保持清楚的内边距。
* prototype 内所有原生按钮统一通过一个共享 `Button` 组件渲染，不允许功能页面继续直接声明 `<button>`。
* `Button` 复用 `vidorra-life` 的物理按钮交互模型：底部 inset 凸起、轻投影、hover 摊平、active 下压，以及 primary / ghost / danger / quiet / icon / plain 六种语义。
* 参考按钮的暖棕配色必须映射到择途现有冷苔绿、纸面、风险色和焦点 token；复制交互与结构，不引入第二套品牌色。
* 复杂对象入口、分段控件和遮罩仍由同一个 `Button` 组件渲染，但使用 `plain` 语义保留其专用结构；链接保持 `<a>` 语义。
* 落地页品牌、Hero 标题和编辑式段落标题必须使用统一的中文 serif 字体 token；token 缺失时不得静默回退为全局无衬线。

## Decision (ADR-lite)

**Context**：现有登录封面不足以说明产品，而拆分落地页与登录页又违背本次目标；同时 prototype 没有真实认证后端。

**Decision**：在未认证状态渲染一页完整但克制的融合首页，唯一主行动继续调用现有 `onLogin` 演示入口。页面结构收敛为品牌栏、融合首屏、三步工作方式、合并后的所有权与顾问边界、简短收尾；相同承诺不跨区块重复。

**Consequences**：可以在不虚构能力的前提下验证正式首页叙事；未来接入真实认证时需要把当前入口区域替换为所有者账户认证，但页面信息架构无需重做。

### Pattern Language Extension

**Context**：用户确认 `D:/Code/Study/vidorra-life/zed.html` 的结构性图案也应进入本次参考范围。

**Decision**：取消菱形节点和独立斜线舱壁；Hero 只保留非常轻的线性边轨，产品预览只保留局部研究网格。点阵、条码和其他纹样不得与它们在同一区域叠加。Header 改用冷苔绿纸面色，不建立第二套暖色品牌系统。

**Consequences**：页面的识别度更多来自留白、编辑式排版和真实产品预览，而不是参考项目符号；必须重新验证首屏层级、页面总长度、移动端溢出和入口闭环。
