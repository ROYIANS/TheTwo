# ADR-0020：机会判断给出明确但非强制的行动建议

## Context

完成职位与公司调查后，系统可以只展示证据和多个判断维度，也可以给出综合分数，或者进一步形成清晰的行动建议。只展示资料会把最困难的综合判断继续留给用户；单一分数虽然便于排序，却容易掩盖价值偏好、证据缺口和判断过程。

择途的定位是批判性的职业顾问，而不是职位资料库或替用户决策的自动化系统，因此需要在“提供有用判断”和“保留用户主体性”之间建立明确边界。

## Decision

1. 对具体机会给出明确但非强制的行动建议，例如“值得投入”“谨慎投入”或“暂不投入”。
2. 建议同时展示关键依据、不利证据、风险、机会成本、未知项和证据强弱。
3. 系统说明哪些新信息、用户偏好变化或事实纠正可能改变当前结论。
4. 用户可以质疑、覆盖或忽略建议，并始终保留最终决定权。
5. 不以单一综合匹配分、黑盒排行榜或肯定语气替代可解释的判断过程。
6. 行动建议不会触发自动投递、自动沟通或其他越过用户控制权的外部行动。

## Consequences

正面影响：

* 用户获得可以直接指导下一步的判断，而不只是更多待阅读的信息；
* 建议能够被审视、纠正，并随新增证据而变化；
* 产品的批判性顾问角色和证据优先原则落实到具体机会判断中；
* 用户主体性与系统表达明确立场可以同时保留。

代价与风险：

* 系统必须处理用户偏好、现实限制和证据强弱，不能依赖简单关键词匹配；
* 行动建议可能被用户误解为确定结论，需要持续展示不确定性和适用条件；
* 不同机会之间的比较与排序需要保留多维依据，产品表达会比单一分数更复杂。

## Alternatives Considered

### 只展示证据和判断维度

最克制，但没有完成职业顾问应承担的综合分析，用户仍需自己拼接结论，未采用。

### 只提供综合匹配分和排行榜

便于快速排序，但容易制造虚假精确感并隐藏价值判断与未知项，未采用。

### 系统替用户自动执行建议

可以减少操作，但越过用户对关键职业行动的控制权，并与不自动海投的边界冲突，未采用。

## Supersession

无。
