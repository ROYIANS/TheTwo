# ADR-0017：第一版以简历或基本经历加结构化访谈启动

## Context

建立职业画像可以要求用户先导入简历、代码平台、项目文档、作品集和绩效材料，也可以只通过自由对话完成，或者用现有简历与 Agent 主导的结构化访谈结合。

深度材料导入能提供更多证据，但首次使用负担高，会延迟用户开始筛选岗位；自由对话启动快，却容易遗漏时间、职责和项目事实，也会在生成简历时重复整理。

## Decision

1. 第一版建立初步职业画像的最低输入是现有简历或基本工作经历，加一轮由 Agent 主导的结构化访谈。
2. 简历或基本经历负责提供事实骨架；Agent 负责主动发现缺口并追问。
3. 结构化访谈重点补齐职责、项目、行动、成果、能力证据、职业目标、现实限制和不确定项。
4. 用户确认或纠正系统整理出的职业事实后，系统生成或完善基础简历。
5. GitHub、项目文档、作品集、绩效材料和其他工作记录作为可选证据逐步导入，不阻塞首次画像和基础简历生成。
6. 启动过程不要求用户先维护完整证据库，也不把传统长表单机械地改写成聊天问答。

## Consequences

正面影响：

* 用户可以利用已有简历快速开始；
* Agent 能够主动发现简历遗漏和模糊表述；
* 后续证据可以逐步增强画像，而不需要一次准备齐全；
* 访谈结果可以直接服务基础简历和后续职位判断。

代价与风险：

* 初步画像可能仍依赖用户记忆和现有简历中的偏差；
* 结构化访谈长度需要控制，避免首次使用疲劳；
* 可选证据长期不补充时，部分能力判断仍会缺少强依据；
* Agent 必须避免诱导用户夸大成果或补造数字。

## Alternatives Considered

### 首次使用前完成深度材料导入

画像证据更丰富，但启动门槛过高，不适合发起者即将开始的紧急求职，未采用。

### 只通过自由对话建立画像

启动最快，但事实容易遗漏且后续还要重新整理简历结构，未采用。

## Supersession

无。
