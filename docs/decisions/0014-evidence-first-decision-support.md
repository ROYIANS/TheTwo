# ADR-0014：职业判断采用证据优先的决策支持方式

## Context

批判性的职业顾问需要对用户目标、职位和公司提出判断。系统可以依靠模型的综合直觉直接给出强势结论，可以只呈现客观事实而拒绝判断，也可以在提供建议的同时展示事实来源、推断过程和价值前提。

直接结论使用方便，但模型可能依据错误、过时或不存在的信息；只呈现事实则无法完成复杂的职业权衡。择途需要在有效建议与可审视性之间建立可信标准。

## Decision

1. 择途的所有重要职业判断采用证据优先的决策支持方式。
2. 系统明确区分可验证事实、用户确认的职业事实、AI 推断和依赖用户偏好的价值判断。
3. 外部事实尽可能给出来源和时间；用户事实能够追溯到材料或确认记录。
4. AI 推断说明依据、不确定性和可能的反例，不能伪装成已确认事实。
5. 当信息不足、来源冲突或无法验证时，系统明确表达未知，不使用肯定语气、神秘综合分数或伪造依据制造确定性。
6. 系统可以给出明确建议和优先级，但必须让用户能够理解建议为何成立、在哪些前提变化后会失效。
7. 系统输出是供用户审视的决策信息，不是对公司、职位、用户能力或职业方向的最终裁决。

## Consequences

正面影响：

* 用户能够核验信息并质疑系统建议；
* 公司背调、职业画像和目标规划使用一致的可信标准；
* 信息缺口和冲突不会被模型流畅表达掩盖；
* 建议能够随着来源、目标或现实条件变化而重新评估。

代价与风险：

* 搜集、保存和呈现来源会增加产品复杂度；
* 网络信息本身可能被操纵、过时或互相引用，引用不等于真实；
* 过多证据可能增加用户认知负担，需要设计信息层级；
* 某些职业判断无法获得强证据，系统仍需在诚实表达不确定性的同时提供帮助。

## Alternatives Considered

### 允许 AI 依靠综合判断直接给出结论

表达简洁，但无法验证的强势判断容易误导用户，未采用。

### 只呈现客观事实，不提供判断

最谨慎，但把复杂分析重新交还用户，无法实现职业顾问价值，未采用。

## Supersession

无。
