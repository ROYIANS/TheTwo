# ADR-0016：申请就绪交付完整申请决策包

## Context

第一版已经确定以“申请就绪”为终点，但仍需明确就绪意味着只生成简历和打招呼内容，还是同时提供申请重点、待确认问题与风险提示，或者进一步包含完整面试准备。

只生成文本无法充分利用前序公司背调和机会判断；提前生成完整面试方案则会把尚未获得面试的阶段带入第一版范围。

## Decision

1. 第一版的“申请就绪”交付完整申请决策包。
2. 申请决策包至少包含岗位定制简历、打招呼内容、应重点强调的经历与能力证据、需要向招聘方确认的问题、当前未知项和风险提醒。
3. 每项表达都应能追溯到职业画像中的已确认事实。
4. 系统可以建议如何选择、排序和表达事实，但不能补写用户没有做过的经历、职责、成果或数字。
5. 用户审核和修改申请决策包后，亲自在招聘平台使用。
6. 完整面试准备、模拟面试和面试复盘在获得面试或进入后续阶段时处理，不属于第一版申请决策包。

## Consequences

正面影响：

* 机会判断能够直接转化为可执行的申请行动；
* 背调发现的未知项和风险会进入沟通策略，而不是停留在分析报告中；
* 岗位定制材料共享同一事实来源，减少虚构和前后矛盾；
* 第一版仍然避免提前扩张到完整面试流程。

代价与风险：

* 申请决策包比单次文本生成更复杂，需要保持各部分一致；
* 不同招聘平台的沟通长度和语境不同，后续需要适配；
* 风险提醒和待确认问题需要控制语气，避免让用户机械复制不合适的表达；
* 用户仍需判断哪些建议适合实际沟通情境。

## Alternatives Considered

### 只生成岗位定制简历和打招呼内容

范围更小，但没有把机会判断中的风险、未知和证据优势转化为申请策略，未采用。

### 申请前同时生成完整面试准备

覆盖更完整，但会增加第一版范围，并为可能不会进入面试的职位提前投入大量工作，未采用。

## Supersession

无。
